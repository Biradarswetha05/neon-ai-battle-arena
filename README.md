# ⚔️ Neon AI Battle Arena

A futuristic cyberpunk Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## Features

- Smart AI opponent
- Difficulty levels
- Health system
- Sound effects
- Match history
- Win streaks
- Responsive design
- Cyberpunk neon UI

## Tech Stack

- HTML5
- CSS3
- JavaScript
